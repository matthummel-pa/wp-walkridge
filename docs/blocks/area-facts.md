# Area Facts

`walkridge/area-facts` · packaged at `blocks/area-facts/`

![ Area Facts ](screenshots/area-facts.png)

## When to use

Area (optional)

## How to insert

1. Inserter → **Walkridge** → **Area Facts**.
2. Select the block. The canvas shows a live PHP preview.
3. Parking, meeting point, and directions as three cards. Prefer Area Map when a photo/map is needed.

## Images and media

None.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
