# Page Intro

`walkridge/page-intro` · packaged at `blocks/page-intro/`

![ Page Intro ](screenshots/page-intro.png)

## When to use

Tours, Guides, Area, Contact, Refund

## How to insert

1. Inserter → **Walkridge** → **Page Intro**.
2. Select the block. The canvas shows a live PHP preview.
3. Insert as the first block on inner pages. Empty fields fall back to demo copy for that page slug.

## Images and media

None required.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
