# Pathway Cards

![ Pathway Cards ](screenshots/pathway-cards.png)

## When to use

Home

## How to insert

1. Inserter → **Walkridge** → **Pathway Cards**.
2. Select the block. The canvas shows a live PHP preview.
3. Edit left/right titles, links, and optional custom images.

## Images and media

Two images (preset or upload).

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
