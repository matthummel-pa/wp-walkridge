# Battle Timeline

`walkridge/timeline` · packaged at `blocks/timeline/`

![ Battle Timeline ](screenshots/timeline.png)

## When to use

Home

## How to insert

1. Inserter → **Walkridge** → **Battle Timeline**.
2. Select the block. The canvas shows a live PHP preview.
3. One day per line: `Day | Place | Note`.

## Images and media

None.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
