# Info Strip

`walkridge/info-strip` · packaged at `blocks/info-strip/`

![ Info Strip ](screenshots/info-strip.png)

## When to use

All concept pages

## How to insert

1. Inserter → **Walkridge** → **Info Strip**.
2. Select the block. The canvas shows a live PHP preview.
3. Place under the intro. Toggle phone, address, and hours. Band style changes the strip background.

## Images and media

None.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
