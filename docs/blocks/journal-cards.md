# Journal Cards

`walkridge/journal-cards` · packaged at `blocks/journal-cards/`

![ Journal Cards ](screenshots/journal-cards.png)

## When to use

Home

## How to insert

1. Inserter → **Walkridge** → **Journal Cards**.
2. Select the block. The canvas shows a live PHP preview.
3. `Eyebrow | Title | Text | URL | imageKey`. imageKey is cannon, wentz, or downtown.

## Images and media

Theme preset photos.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
