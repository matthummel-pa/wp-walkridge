# Section Heading

`walkridge/section-heading` · packaged at `blocks/section-heading/`

![ Section Heading ](screenshots/section-heading.png)

## When to use

Any page

## How to insert

1. Inserter → **Walkridge** → **Section Heading**.
2. Select the block. The canvas shows a live PHP preview.
3. Use when a section needs a heading without another Walkridge block. Set heading level and alignment from the toolbar.

## Images and media

Optional alternate background.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
