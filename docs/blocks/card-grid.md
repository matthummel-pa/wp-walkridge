# Card Grid

`walkridge/card-grid` · packaged at `blocks/card-grid/`

![ Card Grid ](screenshots/card-grid.png)

## When to use

Home, Tours, Contact

## How to insert

1. Inserter → **Walkridge** → **Card Grid**.
2. Select the block. The canvas shows a live PHP preview.
3. Variant `expect` or `feature`. Rows: `Title | Text` or `Title | Text | Eyebrow | URL`.

## Images and media

None.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
