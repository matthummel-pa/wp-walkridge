# Home Hero

`walkridge/home-hero` · packaged at `blocks/home-hero/`

![ Home Hero ](screenshots/home-hero.png)

## When to use

Home

## How to insert

1. Inserter → **Walkridge** → **Home Hero**.
2. Select the block. The canvas shows a live PHP preview.
3. Insert **Walkridge → Home Hero** at the top of the Home page. Edit eyebrow, title, path cards, stats, marquee, buttons, and background image in the sidebar. Use one per page.

## Images and media

Preset or custom background; overlay/height if advanced attrs are set.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
