# Tour Grid

`walkridge/tour-grid` · packaged at `blocks/tour-grid/`

![ Tour Grid ](screenshots/tour-grid.png)

## When to use

Home, Tours

## How to insert

1. Inserter → **Walkridge** → **Tour Grid**.
2. Select the block. The canvas shows a live PHP preview.
3. Renders published WooCommerce tours. Set max count, filters, and compare table.

## Images and media

Requires tour products or the setup seed.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
