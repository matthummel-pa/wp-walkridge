# Contact Desk

`walkridge/contact-desk` · packaged at `blocks/contact-desk/`

![ Contact Desk ](screenshots/contact-desk.png)

## When to use

Contact

## How to insert

1. Inserter → **Walkridge** → **Contact Desk**.
2. Select the block. The canvas shows a live PHP preview.
3. Office heading plus form. Toggle NAP and form independently. One per page.

## Images and media

None.

## Do not

- Do not paste this layout into a classic HTML widget — it will skip block settings.
- Do not store this copy in page custom fields.
