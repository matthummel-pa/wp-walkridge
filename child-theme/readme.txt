Child theme for Walkridge. Template: walkridge.

== Description ==

Use this child theme for CSS and template overrides that should survive parent updates. Activate after the parent Walkridge theme is installed. Keep the parent folder named `walkridge`.

Author: Matt Hummel — https://matthummel.com/

== Installation ==

1. Install and activate the parent theme `walkridge`.
2. Upload `walkridge-child` (or the child zip) via Appearance → Themes.
3. Activate Walkridge Child.
4. Add CSS to `style.css` or enqueue assets from `functions.php`.
